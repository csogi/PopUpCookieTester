How to allow pop-ups and cookies

Menu names change between browser versions; these are the usual locations.

Chrome
  • Pop-ups: when a pop-up is blocked, select the blocked pop-up icon at the right end of the address bar, choose “Always allow pop-ups and redirects”, then select Done. Or go to Settings › Privacy and security › Site settings › Pop-ups and redirects.
  • Third-party cookies: Settings › Privacy and security › Third-party cookies. Choose “Allow third-party cookies”, or add the site under “Sites allowed to use third-party cookies”. Incognito windows block them by default.
Microsoft Edge
  • Pop-ups: Settings › Cookies and site permissions › Pop-ups and redirects. Add the site under “Allow”.
  • Third-party cookies: Settings › Cookies and site permissions › Manage and delete cookies and site data. Turn off “Block third-party cookies”, or add the site under “Allow”. Strict tracking prevention can also block some sites.
Firefox
  • Pop-ups: select Options in the yellow “Firefox prevented this site from opening a pop-up window” bar, then allow pop-ups for the site. Or go to Settings › Privacy & Security › Permissions › Block pop-up windows › Exceptions.
  • Third-party cookies: Firefox keeps a separate set of cookies for each site you visit (Total Cookie Protection). If an embedded tool fails, select the shield icon in the address bar and turn off Enhanced Tracking Protection for that site.
Safari (Mac, iPhone, iPad)
  • Pop-ups on Mac: Safari › Settings › Websites › Pop-up Windows. Set the site to “Allow”.
  • Pop-ups on iPhone and iPad: Settings › Apps › Safari, then turn off “Block Pop-ups”.
  • Third-party cookies: Safari blocks them by default (“Prevent cross-site tracking”). Turning that off allows them but reduces privacy; try test 4’s “Allow access” button first.
